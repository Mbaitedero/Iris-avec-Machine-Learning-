# Iris avec Machine Learning

Classification du célèbre jeu de données **Iris** (longueur/largeur des sépales et pétales → espèce de fleur parmi 3 classes), accompagnée d'une petite application de prédiction interactive.

## 📂 Contenu

- `classification Iris.ipynb` — exploration des données et comparaison de modèles de classification
- `Porjet1.ipynb` — notebook complémentaire d'expérimentation
- `App.py` — application de prédiction (chargement du modèle sérialisé et saisie utilisateur)
- `logistic_regression_model.pkl` — modèle de régression logistique entraîné et sauvegardé

## 🛠️ Stack technique

Python · Scikit-learn · Pandas · Jupyter Notebook
